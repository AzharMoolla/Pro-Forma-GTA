# Example user journeys and edge cases

## A. Small townhouse feasibility
Enter location, lot area, proposed townhouses, net sellable space, land asking price, floor area, parking and rough timing. Choose Quick; set cost and selling price estimates; receive budget, expected margin, sources/uses, sensitivity to sale prices. Expose all assumptions as user-entered, not authoritative local valuation.

## B. 250-unit purpose-built rental development
Choose Professional; input unit mix (studio/1BR/2BR/3BR), areas, market/affordable rents, garage, phases, permits, financing and timeline. Software screens MLI Select / ACLP possible eligibility with status, explains Ontario rental DC treatment, and applies **sourced and verified** city/regional/school levies. Analyst sees monthly interest/cash requirement/DSCR and source dates, not guaranteed public funding.

## C. Multi-phase mixed-use project
Choose Institutional; separate residential+retail uses, phase timings, independent costs and revenues, sale/refinance assumptions, multiple loan tranches and equity waterfall; branch into downside/rate shock cases. Design preserves same core engine and flags cross-phase financing costs and unsupported tax assumptions.

## D. A new policy changes
Source watcher detects a reviewed municipal DC revision. The approved project remains frozen. User opens side-by-side old/new policy rule, identifies specific project dates/uses affected, creates candidate scenario, inspects changes to interest carry, peak equity and IRR, then explicitly saves new revision.

## E. Program closes
New project loads historical CMHC AHF workbook. System shows "AHF new applications closed as of Dec 19, 2025" and blocks assumed new-program receipts; prompts separate legacy/committed status or alternate potentially open program. Other projects' historical financing not destroyed.

## F. Formula error import
User imports a worksheet with an actual-FSI GFA input pointing to expected FSI. Import adapter maps data as **unverified proposed inputs** and flags inconsistent dependencies, preserving source cell locations. Validation test changes expected FSI alone and confirms actual GFA remains unaffected after fix.
